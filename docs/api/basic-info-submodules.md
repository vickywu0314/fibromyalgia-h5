# 基本信息 · 患者评估与病史（10 个子模块，查看）

基本信息页（`fibromyalgia-basic-info/basic-info.html`）下有 10 个子模块。在随诊查看流程中它们都只读展示，不能修改。

## 1. 页面流程

```
基本信息页 ?patientId&caseId&mode=view
  ├─ 请求 /api/fms/patient/case/detail?parts=jbxx（见 case-detail.md）
  ├─ 子模块行按数据显示「已填写 / 未填写」，标题右侧显示「已完成 n/10」
  └─ 点击子模块
       ├─ 把 jbxx.{子模块 key} 写入 sessionStorage.fms_case_detail_prefetch（part 记为 jbxx.{key}）
       └─ 跳转子模块查看页 ?patientId&caseId&mode=view
            └─ 读取预取数据；没有（刷新、直接打开）则请求 parts=jbxx 后取 jbxx.{key}
```

| 子模块 | 数据 key | 查看页 | 说明 |
|---|---|---|---|
| 本病治疗史 | treatmentHistory | `benbing-zhiliaoshi/kaiyao-huizong.html` | 原「开药汇总」页，查看模式下用接口数据，条目不可点 |
| 既往疾病史 | diseaseHistory | `jiwang-bingshi/view.html` | 新增查看页；`index.html` 仍为添加入口 |
| 合并药物 | concomitantMedication | `hebing-yaowu/view.html` | 新增查看页；`index.html` 仍为添加入口 |
| 中枢敏化程度（CSI-9） | csi | `fibromyalgia-basic-info/csi.html` | 表单回显只读 |
| 间接成本评估 | work | `fibromyalgia-basic-info/work.html` | 表单回显只读 |
| 人体成分分析 | bodyComposition | `fibromyalgia-basic-info/body-composition.html` | 表单回显只读，显示已上传报告图片 |
| 人格评估（TIPI-C） | tipi | `fibromyalgia-basic-info/tipi.html` | 表单回显只读 |
| 膳食摄入评估（SFFQ） | sffq | `fibromyalgia-basic-info/sffq.html` | 表单回显只读 |
| 压痛点（TPC） | tpc | `fibromyalgia-basic-info/tpc.html` | 表单回显只读 |
| 纤维肌痛症状量表（FS） | fs | `fibromyalgia-basic-info/fs.html` → `wpi.html` / `sss.html` | 目录页显示 WPI、SSS 是否已填写，点击进入各自查看页 |

- 查看模式下隐藏填写进度条、保存按钮和上传入口；列表页只保留「返回」。
- 不带 `mode=view` 打开时，各页面仍是原来的填写流程，不受影响。
- 随诊病历页（`case-record.html`）在「基本信息」下的「患者评估与病史」中同样展示这 10 个子模块。

## 2. 接口与数据结构

不新增接口。子模块数据嵌在 `/api/fms/patient/case/detail` 的 `data.jbxx` 里，与基本信息的字段同级：

```json
{
  "success": true,
  "data": {
    "jbxx": {
      "visitDate": "2024-05-10",
      "name": "张三",
      "treatmentHistory": { "xiyao": [], "zhongyaoTangji": [], "feiYaowuLiaofa": [], "zhongchengyao": [] },
      "diseaseHistory": [],
      "concomitantMedication": [],
      "csi": {}, "work": {}, "bodyComposition": {}, "tipi": {}, "sffq": {}, "tpc": {},
      "fs": { "wpi": {}, "sss": {} }
    }
  }
}
```

- 没有填写的子模块：列表类返回 `[]`，表单类返回 `{}`，或不返回该 key。
- 表单类子模块沿用通用约定：字段名与页面控件 `name` 一致，单选 / 下拉返回选项文字，多选返回数组，日期 `yyyy-MM-dd`，图片返回 URL。

## 3. 本病治疗史 — `jbxx.treatmentHistory`

按治疗类别分组，每类为数组：

```json
{
  "treatmentHistory": {
    "xiyao": [ { "medication": "艾司唑仑", "frequency": "日1次", "dose": "1", "unit": "片/粒", "startDate": "2023-01-01", "ongoing": "否", "endDate": "2023-06-01", "reason": "不良反应" } ],
    "zhongyaoTangji": [ { "name": "汤剂1", "startDate": "2022-01-22", "ongoing": "是" } ],
    "feiYaowuLiaofa": [ { "name": "八段锦", "duration": "60", "frequency": "每周一次", "startDate": "2022-03-01", "ongoing": "是" } ],
    "zhongchengyao": [ { "name": "痛祺胶囊", "frequency": "日1次", "dose": "4", "startDate": "2022-05-01", "endDate": "2022-08-01" } ]
  }
}
```

| 类别 key | 类别 | 填写页 |
|---|---|---|
| xiyao | 西药 | `benbing-zhiliaoshi/add-xiyao.html` |
| zhongyaoTangji | 中药汤剂 | `benbing-zhiliaoshi/add-zhongyao-tangji.html` |
| feiYaowuLiaofa | 非药物疗法 | `benbing-zhiliaoshi/add-fei-yaowu-liaofa.html` |
| zhongchengyao | 中成药 | `benbing-zhiliaoshi/add-zhongchengyao.html` |

| 字段 | 类型 | 适用类别 | 说明 |
|---|---|---|---|
| medication | string | xiyao | 西药名称 |
| name | string | 其余三类 | 名称（中药汤剂按录入顺序为「汤剂1」「汤剂2」…） |
| frequency | string | xiyao、zhongchengyao、feiYaowuLiaofa | 频次。药物：日1次 / 日2次 / 日3次 / 按需服用；非药物疗法：每天一次 / 每周一次 / 每周二次 / 每周三次 / 按需进行 |
| dose | string | xiyao、zhongchengyao | 单次用量 |
| unit | string | xiyao、zhongchengyao | 用量单位，默认「片/粒」 |
| duration | string | feiYaowuLiaofa | 单次时长（分钟） |
| startDate | string | 全部 | 开始日期 yyyy-MM-dd |
| ongoing | string | xiyao、zhongyaoTangji、feiYaowuLiaofa | 是否沿用至今：是 / 否 |
| endDate | string | 全部 | 结束日期 yyyy-MM-dd（ongoing 为「否」时） |
| reason | string | xiyao、zhongyaoTangji、feiYaowuLiaofa | 停用原因（ongoing 为「否」时）：疗效不佳或无效 / 症状缓解 / 不良反应 / 病情好转 / 患者自行停用 / 经济原因 / 治疗方案调整 / 疗程结束 / 其他 |

查看页按「名称 + 频次/用量 + 起止信息」逐条显示；某类没有记录时显示「暂无记录」。

## 4. 既往疾病史 — `jbxx.diseaseHistory`

数组，每条一种疾病：

```json
{ "diseaseHistory": [ { "category": "huxi", "categoryLabel": "呼吸系统疾病", "name": "哮喘", "years": 2 } ] }
```

| 字段 | 类型 | 说明 |
|---|---|---|
| category | string | 疾病类别代码，同填写页文件名：fengshi 风湿性疾病 / huxi 呼吸系统疾病 / xiaohua 消化系统疾病 / xunhuan 循环系统疾病 / neifenmi 内分泌和代谢性疾病 / shen 肾病系统 / guke 骨科系统 / shengzhi 生殖系统 / xinli 精神心理疾病 / tengtong 慢性重叠疼痛综合征 |
| categoryLabel | string | 疾病类别名称 |
| name | string | 疾病名称（选「其他」时为填写的名称） |
| years | number | 病程（年），可为空 |
