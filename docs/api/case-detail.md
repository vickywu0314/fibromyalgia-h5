# 随诊详情接口（查看模式）— follow-up-entry.html 及各模块页

## 1. 页面流程

```
follow-up-list.html 点击某条随访
  └─ follow-up-entry.html?patientId={患者ID}&followUpId={随诊ID}&name={姓名}&date={随访日期}
       ├─ 点击 7 个模块之一（单模块查看）
       │    ├─ 请求 /api/fms/patient/case/detail?parts={模块代码}
       │    ├─ 成功：数据写入 sessionStorage.fms_case_detail_prefetch { caseId, part, savedAt, data }
       │    └─ 跳转 {模块页}?patientId={患者ID}&caseId={随诊ID}&mode=view
       │         ├─ 读取并删除预取数据（同一随诊、同一模块、60 秒内有效）
       │         ├─ 没有预取数据（刷新、预取失败）→ 模块页自己请求
       │         └─ 按字段名回显到表单，全部控件只读
       └─ 点击「查看随诊病历」（整次随诊查看）
            ├─ 请求 /api/fms/patient/case/detail?parts=jbxx,bsbq,zhpd,fzjc,bqpg,zlfa,blsj
            ├─ 成功：写入同一个预取 key，part 记为 all
            └─ 跳转 case-record.html?patientId={患者ID}&caseId={随诊ID}&name={姓名}&date={随访日期}
                 └─ 一个长页面依次显示 7 个模块，只显示已填写的项，模块没有数据时显示「未填写」
```

- 单模块查看由 URL 参数 `mode=view` 开启；不带该参数时模块页仍是原来的填写页。
- 单模块查看已接入：基本信息（含 10 个子模块，见 basic-info-submodules.md）、病史病情、证候判断、辅助检查、不良反应。查看模式下隐藏填写进度条、「保存并返回」按钮和上传入口，输入框、单选、多选、下拉全部禁用。基本信息页的「患者评估与病史」子模块入口仍可点击。
- 病情评估和治疗方案是「目录页 + 多个子页」结构，整次随诊的数据在随诊病历页查看。
- 随诊病历页把选项值换成题目和选项文字显示，题目、选项和单位来自 `js/case-record-schema.js`。该文件由 `scripts/extract-case-schema.mjs` 从各模块填写页自动提取生成，页面题目改动后重新运行即可。
- 公共实现：`js/case-view.js`（`CaseView.fetchParts / fetchPart / init / fill`），`css/case-view.css`；随诊病历页 `case-record.html`、`js/case-record.js`、`css/case-record.css`。

## 2. 接口定义

```
GET /api/fms/patient/case/detail?patientId={患者ID}&doctorId={医生ID}&caseId={随诊ID}&parts={模块代码}
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| patientId | long | 是 | 患者 ID |
| doctorId | long | 是 | 医生 ID，App 内 `WenwenClass.getUserId()`，localhost 开发为 `5065` |
| caseId | long | 是 | 随诊 ID，即随诊列表的 `data[].id` |
| parts | string | 是 | 模块代码，多个用逗号分隔；单模块查看传一个，随诊病历页传全部 7 个 |

| 模块代码 | 模块 | 页面 |
|---|---|---|
| jbxx | 基本信息 | `fibromyalgia-basic-info/basic-info.html` |
| bsbq | 病史病情 | `fibromyalgia-condition-history/condition-history.html` |
| zhpd | 证候判断 | `fibromyalgia-syndrome-differentiation/syndrome-differentiation.html` |
| fzjc | 辅助检查 | `fibromyalgia-auxiliary-exam/auxiliary-exam.html` |
| bqpg | 病情评估 | `bingqing-pinggu/index.html` |
| zlfa | 本次治疗方案 | `zhiliao-fangan/index.html` |
| blsj | 不良反应 | `fibromyalgia-adverse-reaction/adverse-reaction.html` |

### 返回

```json
{
  "success": true,
  "message": "",
  "data": {
    "jbxx": { "visitDate": "2024-05-10", "name": "张三", "gender": "女" }
  }
}
```

- `data` 中以模块代码为 key，只返回请求的模块。
- `success` 不为 `true` 时，页面显示 `message`（没有则显示「随诊详情加载失败，请稍后重试」）。
- 该随诊尚未填写某模块时，返回空对象 `{}` 或不返回该 key，页面显示空表单。

### 字段约定（所有模块通用）

- **字段名与页面表单控件的 `name` 一致**（多选控件的 `name[]` 去掉 `[]`）。
- 单选、下拉：返回控件的 `value`。前五个模块的 value 就是选项文字（如 `"女"`、`"3级"`）；病情评估量表的 value 是分值代码（如 `"0"`），文字见第 7 节。
- 多选：返回字符串数组，如 `["肝郁气滞", "焦虑易怒"]`。
- 图片：返回图片 URL（数组或字符串），不返回 base64。
- 日期：`yyyy-MM-dd`。
- 数字：number。
- 没有填写的字段返回 `null` 或不返回。

## 7. bqpg 病情评估

`data.bqpg` 按量表分组，key 为量表代码。不同量表有同名字段（如 vas 和 painDetect 都有 `pain3`），所以不能平铺：

```json
{ "bqpg": { "vas": { "vas": 6, "painNature": ["酸痛"] }, "had": { "had_a1": "2" } } }
```

- 单选题返回选项值（`0`、`1`…），页面按下表换成选项文字显示。
- 标尺题返回 0–10 的 number。
- `painDetect.painRegions` 为疼痛部位数组，如 `["正面-1", "背面-40"]`。
- 没有填写的量表不返回或返回 `{}`。

| 量表代码 | 量表 | 页面 |
|---|---|---|
| vas | 疼痛评估 | `bingqing-pinggu/vas.html` |
| fiqr | 整体病情评估：修订版纤维肌痛影响问卷（FIQR） | `bingqing-pinggu/fiqr.html` |
| pcs | 疼痛灾难化评估：疼痛灾难化量表（PCS） | `bingqing-pinggu/pcs.html` |
| mfi20 | 疲劳评估：多维疲劳评价量表（MFI-20） | `bingqing-pinggu/mfi20.html` |
| psqi | 睡眠评估：匹兹堡睡眠质量量表（PSQI） | `bingqing-pinggu/psqi.html` |
| had | 焦虑抑郁评估：医院焦虑抑郁调查量表（HAD） | `bingqing-pinggu/had.html` |

## 8. zlfa 本次治疗方案

`data.zlfa` 按治疗类别分组，每类为数组（可开多条）。没有的类别返回 `[]` 或不返回。

```json
{ "zlfa": {
  "xiyao": [ { "name": "普瑞巴林胶囊", "category": "改善纤维肌痛综合征病情药物", "dose": "75", "unit": "mg", "frequency": "日1次", "adjust": "是", "adjustment": "加量", "reason": "疗效不佳或无效" } ],
  "zhongchengyao": [ { "name": "乌灵胶囊", "dose": "1", "unit": "粒", "frequency": "日1次", "adjust": "否" } ],
  "zhongyaoYinpian": [ { "name": "蠲痹汤", "syndrome": "寒湿痹阻证", "recipe": "蠲痹汤", "prescription": "羌活，独活，桂枝…", "image": "https://…/rx.jpg" } ],
  "feiYaowu": [ { "name": "八段锦", "duration": "60", "frequency": "每周一次" } ]
} }
```

| 类别 key | 类别 | 填写页 |
|---|---|---|
| xiyao | 西药 | `zhiliao-fangan/add-xiyao.html` |
| zhongchengyao | 中成药 | `zhiliao-fangan/add-zhongchengyao.html` |
| zhongyaoYinpian | 中药饮片 | `zhiliao-fangan/add-zhongyao-yinpian.html`、`add-zhongyao-tangji.html` |
| feiYaowu | 非药物疗法 | `zhiliao-fangan/add-fei-yaowu.html` |

| 字段 | 类型 | 适用类别 | 说明 |
|---|---|---|---|
| name | string | 全部 | 药品 / 方剂 / 疗法名称 |
| category | string | xiyao | 药物分类：改善纤维肌痛综合征病情药物 / 改善焦虑、抑郁药物 / 助眠药 / 非甾体抗炎类药物 / 肌松药 / 其他 |
| dose | string | xiyao、zhongchengyao | 剂量 |
| unit | string | xiyao、zhongchengyao | 剂量单位：mg / 片 / 粒 |
| frequency | string | xiyao、zhongchengyao、feiYaowu | 频次：日1次 / 日2次 / 日3次 / 晚1次 / 按需使用；非药物疗法为页面上的频次文字 |
| duration | string | feiYaowu | 单次时长（分钟） |
| instructions | string | 可选 | 用法说明 |
| adjust | string | xiyao、zhongchengyao | 是否调整：是 / 否 |
| adjustment | string | 同上 | 调整内容：加量 / 减量 / 停药 / 换药 |
| reason | string | 同上 | 调整原因：疗效不佳或无效 / 症状缓解 / 不良反应 / 患者自行停用 / 经济原因 / 治疗方案调整 / 疗程结束 / 其他 |
| syndrome | string | zhongyaoYinpian | 中医证型 |
| recipe | string | zhongyaoYinpian | 处方类型（方剂名） |
| prescription | string | zhongyaoYinpian | 处方组成 |
| image | string | zhongyaoYinpian | 处方图片 URL |
