通用约定

  • 所有接口走同源 /api 反向代理，携带 cookie，请求头 X-Requested-With: XMLHttpRequest；GET 超时 10 秒，POST 超时 15 秒。
  • 返回统一为 Result：success === true 才视为成功，失败时页面显示 message。
  • 模块字段名与页面表单控件 name 一致；单选 / 下拉为选项值，多选为字符串数组（key 不带 []），日期 yyyy-MM-dd，数字输入为 number，图片为 URL 数组，未填写的字段不返回 / 不提交。
  • 模块代码：jbxx 基本信息、bsbq 病史病情、zhpd 证候判断、fzjc 辅助检查、bqpg 病情评估、zlfa 本次治疗方案、blsj 不良反应。
